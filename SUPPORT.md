# Support & Community

Thank you for using PrepMind AI! Here is how to find help, report issues, and suggest improvements.

---

## 🔍 Getting Help

Before opening a new issue, please check existing resources:

1. **[Documentation](docs/)**: Review technical guides, architecture overviews, and setup instructions.
2. **[Existing Issues](https://github.com/sahaya-savari/PrepMind/issues)**: Search closed and open issues to see if your question or bug has already been addressed.
3. **[README FAQ & Setup](README.md)**: Common setup, environment variable requirements, and build instructions.

---

## 🐛 Reporting Bugs

If you have encountered a bug or unexpected behavior:

1. Open a new issue at **[GitHub Issues](https://github.com/sahaya-savari/PrepMind/issues/new)**.
2. Provide:
   - A clear, descriptive issue title.
   - Steps to reproduce the problem.
   - Expected behavior vs. actual behavior.
   - Your local environment (Node.js version, OS, browser, commit hash).
   - Relevant terminal logs or console error messages (ensure all API keys and secrets are removed).

---

## 💡 Feature Requests & Ideas

Have an idea to improve the AI tutor, add support for a new competitive exam, or enhance analytics?

- Open a feature request at **[GitHub Issues](https://github.com/sahaya-savari/PrepMind/issues)**.
- Describe the problem your feature solves and how it benefits students and developers preparing for exams.
- Provide any relevant UI/UX mockups, syllabus patterns, or API specifications.

---

## 🔒 Security Inquiries

For sensitive security reports or vulnerability disclosures, please follow our **[Security Policy](SECURITY.md)** rather than opening a public issue.
